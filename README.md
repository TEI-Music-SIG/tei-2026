# Example from Revue des Colonies

The facsimile and edition can be found here and used as a reference: https://revuedescolonies.org/RdCv1n1-fr/ 

## Exploring with Scholarly XML

Open files in `/tei` and try out Scholarly XML features.

`RdCv1n1-fr.xml` includes `entities.xml` and `RdCv1n1-notes.xml`.

`RdCv1n1-fr-standalone.xml` is a "compiled" version.

## CETEIcean rendering

`index.html` renders `RdCv1n1-fr-standalone.xml` using CETEIcean. We can adjust CSS and add behaviors to improve how it looks.
